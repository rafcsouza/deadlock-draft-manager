# Deadlock Draft Manager

Plataforma de pick & ban em tempo real para partidas competitivas de Deadlock.
Inspirada no projeto open-source [deadlockprobr/draft](https://github.com/deadlockprobr/draft).

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Stack

- Next.js 15 + React 19
- Tailwind CSS 4
- Heróis via [Deadlock API](https://api.deadlock-api.com)
